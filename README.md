#✅ Web Design Mini Project – Todoist-Inspired Website

#📌 Project Title
**Todoist-Inspired Web Design**

##📝 What This Project Does
This project is a **responsive, styled front-end website** designed to look and function(little bit)similarly to the official [Todoist](https://todoist.com) homepage. It demonstrates modern UI components like:

- 🔽 Dropdown menus
- 🎬 Embedded video section with custom controls
- 📷 Logos and icons using [Remix Icon](https://remixicon.com/)
- ✅ A simple task submission demo (task entry + list)
- 📝 Sample tasks display using styled cards
- 📄 Table layout for displaying or submitting tasks
- 📱 Responsive design layout using Flexbox and media queries

---

## 🚀 How to Open the Project

1. Download or clone the project folder.
2. Make sure the following files are in the same directory:
   - `index.html`
   - `style.css`
   - `script.js`
   - `video4.mp4`
   - Any image files (like `img1.png`, `img2.png`)
3. Open index.html in any modern web browser (e.g., Chrome, Firefox, Edge).
4. Scroll through the pages to view interactive sections like dropdowns, video demo, and task form.

## 🔧 Features Implemented

- Fixed header with navigation and dropdown menus
- Hero section with heading, subtext, and CTA button
- Embedded marketing-style UI image
- Logos and testimonials from fake reviewers
- Video demo with play, pause, and replay controls
- Task input demo (live on the page)
- Login message with emoji
- Fully responsive layout using CSS Flexbox
- Page sections: `#page1` to `#page5` with different content blocks
